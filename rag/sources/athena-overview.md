# ATHENA Overview

ATHENA is a local-first personal AI assistant project for engineering, learning, and personal productivity.

The current machine is an Apple Silicon Mac with 8 GB memory, so ATHENA should prefer lightweight tools before Docker-heavy services.

Current capabilities:

- Local chat through Ollama
- Honest local-mode behavior with no fake internet claims
- Chat history saved under logs/chats
- Simple long-term memory from memory/profile.md
- Lightweight local document search from rag/sources

Planned capabilities:

- Search personal documents
- Add internet search with source citations
- Add voice input and output
- Add coding assistance
- Add Docker, Kubernetes, Jenkins, and OpenStack integrations
